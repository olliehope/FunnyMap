# Acknowledgements

FunnyMap is an independent modern implementation. The following projects were
studied for high-level architecture, terminology, and lessons from earlier
dungeon-map systems:

- FunnyMap
- BetterMap
- CryptKit
- Skyblocker
- OdinFabric

No source code or room database from those projects is bundled here. Mentioning
a project does not imply its authors endorse FunnyMap or are affiliated with
this repository.

At the revisions audited during the initial design work, FunnyMap was
AGPL-3.0, CryptKit was GPL-3.0-only, Skyblocker was LGPL-3.0, OdinFabric was
BSD-3-Clause, and no license was found in the audited BetterMap revision. Those
licenses are one reason architectural reference was kept distinct from code or
data incorporation. Refer to each upstream project for its current terms.

The bundled `assets/funnymap/icon.png` is a project-specific wordmark and is
covered by the repository's CC0 licensing intent. The bundled production room
database currently contains no third-party definitions. Future assets with
different terms must be documented here before distribution.
