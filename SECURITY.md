# Security Policy

FunnyMap is a local client mod and is not primarily security-sensitive. Please
still disclose privately any issue involving:

- arbitrary code execution;
- malicious room-database or capture payloads;
- unsafe file creation, replacement, or path handling;
- credential, session token, or private-data exposure;
- GitHub Actions, update, artifact, or release-pipeline compromise.

Use GitHub's private vulnerability reporting feature under the repository's
Security tab when it is available. If it is not enabled, contact the repository
owner privately through their GitHub profile before sharing exploit details.
Do not include secrets or weaponized payloads in a public issue.

Include affected versions, impact, reproduction conditions, and a minimal proof
of concept where safe. You may suggest a fix, but disclosure does not require
one.

Incorrect room recognition, server allowed-mod policy questions, anti-cheat
behavior, and alleged game-rule violations are not security vulnerabilities.
Use the normal bug or room-data issue forms for technical misidentification.
